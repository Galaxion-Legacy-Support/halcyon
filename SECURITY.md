# Security

## Reporting a problem

**Please don't open a public issue for a security problem.** Report it privately:

- through GitHub: this repository's **Security** tab, then **Report a vulnerability**; or
- by email to **<security address to be published>**.

Tell us what you found, which version or commit, and how to reproduce it if you can. We'll answer within 7 days.

## What happens next

1. We confirm the problem and make the fix in private.
2. We tell the worlds and hosting companies we know run Halcyon, privately, and give them the fix.
3. We publish the fix, and a note of what it fixes, **30 days** later, or sooner if the problem is already public.
4. We credit you in the release notes, unless you'd rather not be named.

A public fix is a map for attacking servers that haven't updated yet, which is why we wait.

## Getting told about fixes

If you run a Halcyon world and want to hear about security fixes before they're published, write to the security address with your world's name and a contact.

## Supported versions

Only this copy's latest release gets security fixes. Original InWorldz and HalcyonGrid releases are not supported here.
