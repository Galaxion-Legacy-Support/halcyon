# Halcyon — legacy support copy, maintained by Virtual World Research Inc

This is VWRI's maintained copy of Halcyon, based on the work done by InWorldz LLC and its successor HalcyonGrid.  Their work can be found in the HalcyonGrid github organization's repository at: [HalcyonGrid/halcyon](https://github.com/HalcyonGrid/halcyon). We keep it so that worlds still running on the Halcyon platform get security, data-safety and backup-export fixes, while they decide whether, and when, to move.

- What we fix: security, data loss, OAR and IAR export, and building on current systems. No new features.
- Licence: same as the original project. See LICENSE, NOTICE and THIRD-PARTY.md. All original notices are kept.
- Who wrote it: Halcyon's original authors are credited in CONTRIBUTORS.md. This copy is maintained by VWRI's Galaxion Legacy Support Work Group; the original authors are not involved in it.
- Not endorsed by the original authors; their project names are used only to say what this is.
- Support until: Ongoing. Security reports: see SECURITY.md.
- Moving to Galaxion: Halcyon's worlds can move to Galaxion Elysian, which reads their OAR and IAR archives. Check out [Galaxion Elysian](https://github.com/Galaxion-Origins/Galaxion-Elysian).
