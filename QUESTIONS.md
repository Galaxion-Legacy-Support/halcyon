# Questions for research

Questions the Galaxion Legacy Support Work Group needs VWRI's research team to answer about Halcyon. Research reads this file twice a day, so there's no need to send questions on.

Answers come back as a legacy brief (LSB), delivered by pull request into `docs/research/` or handed over directly. A brief carries facts about protocols and viewers, never Galaxion's designs.

## Rules

- Ask about facts: protocols, viewer behaviour, file formats.
- Write in your own words. No code, no passwords, and no one else's personal details.
- Legal or licence questions go to VWRI's legal department, not here.

## Adding a question

Copy the template, give it the next free id, and set `Status: open`. When a brief answers it, set `Status: answered` and name the brief on the Answer line.

```
### LH-000: Short title

- Date: YYYY-MM-DD
- Need: what we need to know.
- For: what the answer decides or unblocks.
- Status: open
- Answer:
```
