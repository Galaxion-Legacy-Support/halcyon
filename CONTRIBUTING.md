# Contributing

Thank you for helping keep Halcyon worlds running.

## What we accept

- Fixes for security, data loss, OAR and IAR export, and building or running on current systems.
- Work on the steps in [ROADMAP.md](ROADMAP.md), including support for features current viewers expect.

We don't accept features beyond what current viewers support, or links to other platforms.

## Where code may come from

- **Your own work,** offered under this repository's BSD-3-Clause licence.
- **Code under a licence that fits BSD-3-Clause** (BSD, MIT, Apache-2.0), with its notice kept and the source named in your pull request. OpenSimulator is BSD-3-Clause, so its later work may be carried across this way.
- **Never** code under the GPL or LGPL, including any viewer's code (the Second Life viewer, Firestorm and the others). You may learn from a viewer how it behaves, but its code doesn't come into this repository.
- **Never** code or files whose licence you don't know.

## How to send a change

1. Open an issue first for anything larger than a small fix.
2. Work on a branch and open a pull request into `main`.
3. Say what you changed, how you tested it, and where any outside code came from.
4. One maintainer's review is needed to merge.

## Keeping original notices

Don't change or remove a copyright or licence notice in an existing file. New files get this header:

```
// Copyright (c) <year>, Virtual World Research Inc and contributors.
// Licensed under the BSD-3-Clause licence; see LICENSE.
```
